1/8 O professor manda o prompt. O app envia junto o catálogo do que aquela máquina sabe executar.
2/8 A API chama o orquestrador com token interno. Nenhuma credencial vai no corpo — só o tutor_id.
3/8 O orquestrador busca no banco a chave de IA daquele professor, cifrada, e decifra só em memória.
4/8 Recupera o contexto da pergunta no Qdrant: aulas gravadas, transcrições e materiais da disciplina.
5/8 O grafo chama o modelo — que responde pedindo uma ferramenta, não texto.
6/8 Ferramenta remota: o orquestrador invoca o tool-service (ou o mcp-service) por HTTP interno.
7/8 Ferramenta que só existe na máquina do professor: volta pela API e desce pelo WebSocket até o app, que executa ali.
8/8 O resultado sobe ao grafo, vira resposta e refaz o caminho de volta até o chat.
